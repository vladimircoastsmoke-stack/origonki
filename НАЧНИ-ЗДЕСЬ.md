# ОриГonki — с чего начать

Голосовые гонки для мероприятий. Игроки кричат в телефон — машины едут на большом экране.

---

## Главное правило

**В корне папки лежат файлы `1-…` … `8-…` с расширением `.command` — это кнопки запуска.**

На Mac: **двойной клик** в Finder. Ничего больше искать не нужно.

| Файл | Когда нажимать |
|------|----------------|
| **1-ТЕСТ-С-ДРУГОМ** | Быстро показать игру другу через интернет |
| **2-ДЕПЛОЙ-НА-RENDER** | Залить на Render (старый хостинг, запасной) |
| **3-ЗАПУСК-ЛОКАЛЬНО** | Разработка на Mac, всё на localhost |
| **4-ТЕСТ-В-WIFI** | Тест с Android в одной Wi-Fi |
| **5-ТЕСТ-НА-IPHONE** | Тест с iPhone (нужен HTTPS) |
| **6-ПУШ-НА-GITHUB** | Отправить код на GitHub |
| **7-АВТО-ДЕПЛОЙ** | Сборка + GitHub + Render пересобирается сам |
| **8-ДЕПЛОЙ-НА-REGRU** | Инструкция деплоя на origonki.ru |

> Mac блокирует запуск? Правый клик → **Открыть**. Или в Терминале:  
> `chmod +x ~/Desktop/Гонки/*.command`

## Карта папок

```
Гонки/                          ← вы здесь
│
├── НАЧНИ-ЗДЕСЬ.md              ← этот файл
├── КОМАНДЫ.md                  ← те же кнопки, подробнее
├── 1-… .command … 8-… .command ← ЗАПУСК (двойной клик)
│
├── apps/                       ← код приложений
│   ├── admin/                  ← панель организатора (ведущий)
│   ├── bigscreen/              ← экран для проектора
│   ├── player/                 ← телефон игрока
│   ├── server/                 ← сервер (Node.js + WebSocket)
│   ├── superadmin/             ← ваш офис модератора
│   └── host/                   ← страница входа организатора
│
├── deploy/
│   └── regru/                  ← деплой на VPS Reg.ru (origonki.ru)
│       ├── deploy.sh           ← запускается НА СЕРВЕРЕ
│       ├── docker-compose.yml
│       └── .env.example        ← скопировать в .env, указать пароль
│
├── scripts/                    ← служебные скрипты (обычно не трогать)
├── packages/shared/            ← общая логика игры
│
├── Dockerfile                  ← сборка для Docker
├── docker-compose.yml          ← локальный Docker
└── render.yaml                 ← настройки Render
```

**Не лезьте в `apps/` и `packages/`, если просто запускаете игру или деплоите.**

## Частые вопросы

**Где пароль супер-админа?**  
В `deploy/regru/.env` на сервере (строка `SUPERADMIN_PASSWORD`). На Mac этого файла нет — он только на VPS.

**Что такое `scripts/`?**  
Внутренние скрипты для `.command`-файлов. Запускайте кнопки из корня, не отсюда.

**Удалил случайно `.command`?**  
Скачайте заново с GitHub или запустите `./scripts/click.sh share` / `dev` / `deploy` из терминала.
