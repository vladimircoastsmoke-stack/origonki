# 🏎️ Команды — запуск в один клик

В корне проекта лежат файлы **`.command`** — на Mac их можно запускать **двойным кликом** в Finder.

| Файл | Что делает |
|------|------------|
| **`1-ТЕСТ-С-ДРУГОМ.command`** | Публичный HTTPS-URL → отправьте другу |
| **`2-ДЕПЛОЙ-НА-RENDER.command`** | Зальёт на GitHub + откроет Render |
| **`3-ЗАПУСК-ЛОКАЛЬНО.command`** | Локальная разработка (4 сервиса) |

> **Ошибка «нет прав доступа»?** Откройте Терминал в Cursor (`Ctrl+\``) и выполните:
> ```bash
> chmod +x ~/Desktop/Гонки/*.command ~/Desktop/Гонки/scripts/click.sh
> ```
> Затем снова двойной клик по файлу. Или: правый клик → **Открыть** (не двойной клик).

> Первый запуск: если Mac спросит «разрешить выполнение» → **Открыть** в настройках безопасности, или правый клик → **Открыть**.

---

## В Cursor / VS Code

`Cmd+Shift+P` → **Tasks: Run Task** → выберите:

- 🏎️ **1. Тест с другом**
- ☁️ **2. Деплой на Render**
- 💻 **3. Запуск локально**

---

## Из терминала (альтернатива)

```bash
./scripts/click.sh share    # тест с другом
./scripts/click.sh deploy   # деплой на Render
./scripts/click.sh dev      # локально
./scripts/click.sh prod     # localhost:3001
```
