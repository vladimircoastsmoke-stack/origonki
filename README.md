# Decibel Racing — Голосовые гонки

Интерактивная игра для мероприятий: игроки управляют машинами силой голоса через микрофон смартфона. Гонка проецируется на большой экран.

## Архитектура

| Компонент | Порт | Описание |
|-----------|------|----------|
| **Admin** | 5173 | Панель ведущего — создание комнаты, QR, старт |
| **Big Screen** | 5174 | Экран для проектора — трасса, countdown, подиум |
| **Player** | 5175 | Контроллер игрока — микрофон, выбор машины |
| **Server** | 3001 | WebSocket-сервер (Socket.io) + REST API |

## Быстрый старт

### Требования

- Node.js 20+
- pnpm 9+

### Установка

```bash
pnpm install
cp .env.example .env
pnpm dev
```

Все 4 сервиса запустятся параллельно через Turborepo.

### Как играть

1. Откройте **Admin** → http://localhost:5173
2. Создайте комнату (выберите игроков, трассу, машины)
3. Откройте **Big Screen** → http://localhost:5174?room=XXXX (код из админки)
4. Игроки сканируют QR-код или переходят на http://localhost:5175/join/XXXX
5. Когда все выбрали машины — нажмите «Старт» в админке
6. Игроки кричат в телефон — машины едут!

## Структура монорепозитория

```
apps/
  admin/       — панель ведущего
  bigscreen/   — экран проектора
  player/      — мобильный контроллер
  server/      — Node.js + Socket.io
packages/
  shared/      — типы, константы, игровая логика
```

## Тесты

```bash
pnpm test
```

Unit-тесты для игровой логики (сглаживание громкости, расчёт прогресса) находятся в `packages/shared`.

## Docker

```bash
docker compose up --build
```

Nginx проксирует все сервисы на порт 80.

## Рекомендации по сети на мероприятии

- **Один Wi-Fi для всех**: сервер, проектор и телефоны игроков должны быть в одной локальной сети
- **Выделенный роутер**: используйте отдельный роутер/точку доступа, не общий гостевой Wi-Fi от площадки
- **5 GHz предпочтительнее**: меньше помех, выше пропускная способность
- **Лимиты**: максимум 10 одновременных комнат, 2–4 игрока в комнате
- **Для тестов из интернета**: используйте ngrok/cloudflared для туннелирования порта 3001

## Переменные окружения

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `PORT` | 3001 | Порт сервера |
| `CORS_ORIGIN` | localhost:5173-5175 | Разрешённые origins |
| `VITE_SERVER_URL` | http://localhost:3001 | URL сервера для фронтенда |
| `VITE_PLAYER_URL` | http://localhost:5175 | URL player-приложения для QR |

## iOS Safari — микрофон

На iOS Safari `getUserMedia` требует явного жеста пользователя (нажатие кнопки). Приложение показывает инструкцию, если доступ к микрофону не получен. Убедитесь, что сайт открыт по HTTPS (или localhost).
